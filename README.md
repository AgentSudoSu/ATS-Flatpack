# ATS Flatpack Website

Static GitHub Pages landing page for ATS Flatpack.

## Publish
Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the repository root.

Before publishing, replace `YOUR-EMAIL@example.com` in `index.html` with the business email address.

## Structure
- index.html
- style.css
- script.js
- assets/ats-flatpack-logo.png
